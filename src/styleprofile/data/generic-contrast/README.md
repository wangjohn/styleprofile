# Generic assistant contrast drafts

These 24 original English drafts were composed by the Codex assistant specifically for
styleprofile’s onboarding WP10. No published article, sample essay, external prompt output,
or third-party text was copied. The subjects differ from the sample essays. The corpus
contains four personal essays, four blog posts, four how-to guides, and three each of
opinion pieces, fictional reviews, newsletters, and short stories. Each has 400–900 words.

These intentionally generic drafts span overt headings and lists, balanced advice, and
quieter reflective prose. Shared framing and transitions represent repeated assistant
habits; the topic paragraphs and complete drafts are original. Product, book, event, and
character names are fictional. The drafts are illustrations, not factual advice or reviews.

All files in this directory are original project contributions distributed under the
repository’s MIT license. They are a convenience contrast set, not a representative survey
of any model, a benchmark certification, or proof of a text’s origin. Drafts generated from
a writer’s own briefs are a better comparison; see docs/contrast.md for the recipe.

The acceptance evaluation holds out every examples/llm-drafts document from this set.
No acceptance draft or held-out writer document was used to revise or select these drafts.
